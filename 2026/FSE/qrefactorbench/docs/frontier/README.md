# 面向实际量子收益的前沿核查

日期：2026-09-28；N-059；响应D-038及研究者“做”。这是有边界的前沿审计，
不是穷尽综述、性能复现或已接受的论文贡献。研究对象始终是：**已有经典程序＋工作负载＋
可用量子硬件 → 判断是否值得迁移 → 生成满足原需求的可用实现**。

**结论：自动生成、agent修复、量子算法选择、成本预测、语义检查均已有先例。
下一步应检验“原程序行为要求如何改变量子方案及其收益”，而不是继续增加agent角色。**
这是本次对所查工作作出的研究判断，不是“全领域无人做过”的证明。

## 最接近的工作已经做到哪里

这些工作解决不同层次的问题，没有可据同一指标排出的“全球第一名”。下面是本目标
必须对照的前沿集合；论文数字均为作者报告，本次没有复现其性能。

| 工作 | 已有能力 | 对我们目标的证据边界 |
|---|---|---|
| [C2\|Q⟩](https://arxiv.org/abs/2510.02854) | 从支持的问题代码/JSON提取实例，生成量子程序，推荐设备并解码 | 支持范围内的生成完成率，不等于完整原API行为保持或超过强经典实现；设备推荐器比较量子设备 |
| [QPipe](https://arxiv.org/abs/2607.00939) | 从测试优化需求生成混合应用；多agent、修复、审查、经典参考核对及消融 | 20条需求、理想模拟器；相对GA的生成QUBO目标值，不是硬件端到端加速，也不是任意原源码迁移 |
| [QuaST Decision Tree](https://arxiv.org/abs/2605.18539) | 结构化问题驱动的工作流、后端接入、VQA采样量与不确定性预测；可判不可行 | 需要已建模问题；低于其量子劣势边界不意味着胜过最佳经典端到端方案；自动化模块当前公开状态未核实 |
| [Predict and Conquer](https://arxiv.org/abs/2507.06758) | 用户给问题实例与质量/运行成本约束，预测并选择算法配置 | 已有经典近似对照；依赖训练分布和运行模型，未展示从任意原程序自动恢复行为要求 |
| [Q-READY](https://arxiv.org/abs/2606.16201) | 将需求、建模、策略、硬件可行性和工作流连起来的研究愿景 | 论文明确为vision；例子与模型不能算已实现的自动系统或实测优势 |
| [Quantum Offloading / CORK](https://doi.org/10.1109/CCWC51732.2021.9375948) | 用程序等价检查匹配可卸载计算的早期路线 | 作者摘要中的实验为Shor局部原型的修改版本；本次未取得全文，不扩大结论 |

Q-READY和QPipe有作者重叠，不能把两篇相关论文算成两次独立成功验证。

## 现有技术可以做什么

在限定问题家族、输入范围和明确需求下，已有技术可以组合完成：程序分析/模式匹配、
QUBO或oracle构造、量子程序生成、编译与资源估计、有限测试或受限形式验证、
算法和后端选择，以及有条件的成本/质量预测。**我们必须把这种合理组合作为强基线。**

因此，以下宽泛说法不能再直接作创新：首次经典转量子、首次硬件感知选择、首次成本感知、
首次agent生成修复、首次检查量子替换语义、首次用不确定性拒绝推荐。
Qrisp/Jasp、Qiskit/MQT、QSynth和资源估计器还分别提供编程、编译、受限合成与估计基础设施；
它们的输入和假设不同，不能因为单个工具不覆盖整条链就宣布出现研究空白。

## 哪些是当前技术边界

| 问题 | 本次判断 | 我们可以推进的部分 |
|---|---|---|
| 限定程序与方案，比较同质量下的完整成本 | 可以做，但需要指定输入分布、经典竞争者、硬件和测量协议 | 自动导出与核查比较条件，减少错误推荐；缺少数据时明确未知 |
| 任意源码自动识别所有量子机会 | 所查系统没有展示此能力；受程序理解、规格缺失和已知算法范围限制 | 先支持有清楚行为要求的计算片段；不要求覆盖所有算法 |
| 自动发现新的、有优势的量子算法 | 现有生成/合成结果不能支持通用保证 | 在有限候选空间研究更好的映射与搜索；不承诺解决算法发现总问题 |
| 从小规模模拟稳定预测大规模真实收益 | 只能是带模型和适用范围的预测，不能替代实测 | 验证预测误差、校准与拒绝判断；不是再加一个预测字段 |
| 靠软件弥补不足的量子比特、深度或误差预算 | 编译/分解能改变需求，不能凭空创造物理能力 | 自动揭示瓶颈和所需阈值；分解新增成本要计入 |
| 证明所有经典算法都不如某量子方案 | 不能从有限实验得到；“胜过所选强基线”与复杂性分离是不同命题 | 明确比较集合与条件，不把经验优势升级成普遍定理 |

这里没有声称当前所有QPU、所有任务都没有优势，也没有把“尚未实现/本次未找到”写成
数学不可能。量子查询复杂度、硬件运行时间和用户总时间不能混用。

## 最值得检验的缺口

同一个数学问题，原软件可能要求“任意可行解”“严格最优解”“并列时固定选第一个”
或“惰性枚举全部结果”。这些要求会改变量子编码、重复采样、验证与后处理成本，
也可能改变最终建议。只识别成MaxCut、TSP或搜索，并不足以确定如何替换。

本次所查材料尚未给出充分证据证明：从已有源码自动恢复这些要求，并把要求引起的
方案变化与完整成本一起用于选择，能可靠优于现成工具的合理组合。
**这是一条待验证的研究假设，不是已经坐实的新颖性。**

我们可研究的技术是：让行为约束参与候选方案搜索与淘汰；对必须补上的计算生成成本义务，
再比较满足同一要求的经典和量子方案。其价值必须来自更好的正确决策/实现，
而不是更完整的记录表或更多检查器。详见[诊断计划](NEXT_STUDY.md)。

## 本次实际效果与FSE证据要求

本次排除了数个过宽的创新主张，补齐了此前遗漏的直接竞争者，并确定了可否定的下一步。
没有实现新方法、证明新颖性、得到量子优势，或改变现有十母例和论文结果。

若走这条路线，FSE论文仍需要：明确问题与相对既有工作的技术差异；能复现的实现；
跨独立程序的正确性与决策效果；强组合基线；证明关键机制作用的消融；完整代价和失败分析。
这些对应[官方研究论文要求](https://conf.researchr.org/track/fse-2027/fse-2027-papers)，
不是“使用agent＋做benchmark”即可满足的条件，也不要求我们先宣称真实量子加速。
