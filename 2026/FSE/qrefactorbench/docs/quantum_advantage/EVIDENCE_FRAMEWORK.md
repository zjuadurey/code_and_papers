# 量子优势的证据层级

2026-09-28；前瞻性工作分类，不新增 schema 枚举或正式评分门槛。返回 [总入口](README.md)。

## 层级按主张范围组织

以下不是一个自动晋级总分。理论证明与实验测量是不同证据路线；每条主张仍须独立核对前提。

| 证据层 | 所需依据 | 可以支持 | 不能单凭它支持 |
|---|---|---|---|
| E1 结构映射 | 搜索域/谓词或变量/目标/约束及其与原计算的对应 | 指定条件下可用支持的量子问题形式表达 | 合同保持、硬件可行或收益 |
| E2 行为与语义 | 版本化合同、证明或有范围的测试、反例、经典回退路径 | 已证明的性质，或已测试实例上的一致性 | 未测域正确性、完整迁移正确性或量子优势 |
| E3 资源可行性 | 具体电路/分解、辅助位、深度、运行次数、硬件与纠错模型 | 在给定模型中满足已列资源约束 | 相对于经典方案更优 |
| E4 条件性收益预测 | 合同匹配的经典基线、完整成本模型、参数来源和敏感性分析 | 在明确假设与规模范围内预计有收益 | 已在真实硬件上观测到优势 |
| E5 实测任务收益 | 完整混合运行、同任务经典对照、质量/成功率、测量协议与不确定性 | 在所测实例、硬件和基线下观察到收益 | 对所有经典算法的普遍优势、未测规模收益 |

**理论证据另标范围：** oracle/query 复杂度定理、计算模型下的时间/空间界、以及对经典算法类别的下界，
各自回答不同问题。比较已知算法不等于证明所有经典算法的下界；渐近改善也不直接给出有限规模的实用交叉点。
有适当定理时可以称“在该模型和假设下证明优势”，不必先有硬件实测；必须写清所证明的优势种类。
文献依据及阅读深度见 [S1–S3](SOURCES.md)。

## 将“有一定 qubit”具体化

资源描述至少区分物理与逻辑 qubit；算法寄存器之外的辅助位、反计算和纠错开销不能消失。
硬件 profile 应给出门集/连接性、操作时长、错误模型、测量与控制、允许失败概率；
容错场景还需纠错方案及相应假设。未做物理映射时只能报告逻辑或抽象电路层结果。
这些是拟议记录要求，不表示现有模块已全部实现。

## 收益必须有明确比较条件

| 候选收益指标（尚未选主指标） | 必须固定的比较条件 |
|---|---|
| 更短任务完成时间 | 相同输入/合同、质量目标、成功概率；对照经典实现与硬件明确 |
| 相同预算下更高解质量 | 合同明确允许近似，质量定义与预算一致；同时报告可行性/失败率 |
| 更低总成本或能耗 | 系统边界与计价/测量方法一致；不能用 qubit 数直接替代费用或能耗 |
| 可处理更大规模 | 相同任务与质量/时间/资源限制；所测经典基线失败不等于经典不可解 |

“任何优势”不作为可事后自由选择的评测规则。理论查询减少有研究价值，但不足以单独判定部署值得。
商业采用还可能涉及迁移成本、维护和可用性；若论文只研究运行时收益，应明确该边界。

## 前瞻性成本表达

对输入实例 x、硬件假设 H、质量目标 ε 和失败概率上限 δ，可记录：

```text
T_hybrid = T_preparation + T_classical_control + T_quantum_execution
           + T_communication + T_readout_and_decode + T_validation_and_fallback
S(x, H, ε, δ) = T_classical(x, ε, δ) / T_hybrid(x, H, ε, δ)
```

这是成本项检查框架，不是已实现估算器。每项必须说明是否已包含 shots、重启、优化迭代和失败重试，
避免重复计费；有重叠执行时按实际调度建模，不能机械相加。编译、加载、预处理的复用次数及摊销依据应单列。
开发阶段 LLM/审核成本与部署运行成本分开报告；若部署需再调用 LLM，则计入对应任务成本。
S>1 只代表给定比较条件下的时间优势；语义不匹配时不进行这个比较。
资源约束需同时满足，例如 Q_required(x,H) ≤ Q_available(H)，且两端采用同一物理/逻辑口径。

优势区域可以写为满足合同、资源约束和收益条件的实例/参数集合。若按规模 n 报告，应声明实例族或分布；
同一 n 的实例可能成本不同。不能默认存在单一阈值 n*，或默认超过阈值后永远获益。
参数缺失、区间跨过 S=1 时保留不确定性；不填乐观常数得出采用建议。

## 必须识别的失败模式

- Grover 查询次数改善：仍需实例化 oracle，并计入构造、调用、反计算、成功率及输出合同成本。
- 正确 QUBO：编码正确不证明求解更快，也不证明采样能满足精确最优合同。
- 先经典求解再编码：若预处理已经暴露答案，必须把该成本计入并比较直接返回答案的经典路径。
  仓库已有相关提醒见 [N-054](../../pilot/enhancement/rank-qubo-audit-v0.1/REPORT.md)。
- 经典回退保证正确：报告量子路径贡献与回退成本；整程序通过可能完全来自经典路径。
- 模拟器结果：可支持指定模拟下的行为检查；模拟耗时不是量子硬件运行时间。
- 只测有利实例或弱基线：只能作受限比较；负结果与未完成实例也要保留。
