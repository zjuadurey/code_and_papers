## 已确认的目标

研究者提出：“最终目的是证明一个算法在有一定qubit可用的前提下 能获得加速或者任何量子优势，这样才值得转换。”
讨论进一步明确：需要给定硬件资源、问题规模和输出质量，考察相对于有竞争力经典方案的端到端收益。
研究者认可分析，并要求将讨论及搜索结果分层文档化，贯穿实现与论文写作。
授权依据见 [D-037](../../DECISIONS.md#d-037-quantum-advantage-as-the-long-term-objective-and-layered-evidence-documentation)。

**研究应可靠地判断优势在什么条件下成立，而非预设每个案例必然获得优势。**
具体优势指标、硬件参数、成功阈值和正式评测协议仍待确定；这里的层级和表格是协调者整理的工作方案。
当前正式阶段与版本继续以 [PROJECT_STATUS](../../PROJECT_STATUS.md) 为准。

## 这次讨论形成的共同理解

- “有 qubit”是部分资源条件，还需区分物理/逻辑 qubit，并声明速度、错误与纠错假设。
- “能映射”不等于“保持合同”；“保持合同”不等于“资源可行”；“资源可行”不等于“有收益”。
- 理论复杂度结论、基于模型的运行成本预测、实际硬件测量分别记录。
- 时间、成本、解质量等收益必须先选定比较条件；不得看完结果后挑一个有利指标。
- 精确答案不能静默换成近似答案。原合同允许的随机性与误差也必须保留实际要求。
- 允许报告无交叉点、资源不足或证据未知。未找到优势不等于证明所有量子方案无优势。
