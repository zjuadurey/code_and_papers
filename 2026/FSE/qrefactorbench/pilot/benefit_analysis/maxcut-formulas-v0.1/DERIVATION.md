# 结构推导与潜在收益条件的证明边界

## 一、电路恒等式与任意规模计数

定义正权MaxCut目标`C(x)=Σ_(u,v) w_uv[x_u≠x_v]`，即算子
`C=Σ w_uv(I-Z_u Z_v)/2`。采用`U_C(γ)=exp(-iγC)`，混合算子
`U_B(β)=Π_i exp(-iβX_i)`，初态`|+>^n`。

每条边的`CX(u,v) RZ_v(-γw) CX(u,v)`等于`exp(+iγw Z_uZ_v/2)`。
与`exp(-iγw(I-Z_uZ_v)/2)`仅差无观测影响的全局相位。不同边的ZZ项可交换，
因此可以按matching分组重排。每层每边2CX+1RZ，每节点1RX(2β)，初始每节点1H，
末尾每节点1测量。对任意n、m、p，逐项相加得到：

```
Q_logical = n                 （当前模板无额外逻辑辅助位）
G_unitary = n + p(3m+n)
G_CX = 2pm
G_RZ = pm
G_RX = pn
N_measure = n
```

这不是小规模数据拟合。源码逻辑位数不等于物理位数，也不包括纠错/蒸馏辅助资源。
在m=2n图族中，`G=n(1+7p)`，故100位p=1为800门，p=4为2900门，p=16为11300门。

若按c个互不共享端点的matching顺序调度，每matching为CX/RZ/CX三层，每QAOA层
再加一层RX，制备/测量各一层，则该显式调度深度为`D=2+p(3c+1)`。
每条边最多与2Δ−2条已着色边相邻，所以greedy edge coloring使用`c≤2Δ−1`；
边数为零时c=0。此界依赖逻辑全连接、各类逻辑操作按层计，未包含物理路由和门时差。
它是可构造调度，不宣称最优。生成QASM可被编译器进一步调度/化简，QDK物理耗时单独估算。

## 二、小规模量子态验证的独立核对

实现A直接对每个基态按`exp(-iγC(x))`乘相位，再混合；实现B从全零开始执行
H、CX、RZ、RX。检查两态的`|<a|b>|²=1`允许全局相位，不仅比较均值或一次采样。
混合RX实现共用，所以另以两节点一条单位权边闭式概率检查：

`P(cut)= [1+sin(4β)sin(γ)]/2`。

这来自四个基态振幅的直接展开；γ=π/2、β=π/8时理想割成功率为1。
同时检查全体四节点图和不同层数，包括空图、非连通图和多解tie。
这些有限验证用于查实现错误；任意规模结构成立的依据是第一节的电路恒等式与循环计数。

## 三、由精确回退推导期望优势条件

假设：固定实例；S个串行shots；每shot在给定硬件和可靠证书下，以概率s产生可接受的
原合同输出，且事件iid；整批至少一次成功则接受，否则运行精确经典回退。
每次都检查输出证书，不接受错误解。设：

- t：一次量子执行耗时，包含初始化、门、测量；
- A：所有批次固定成本，含构造、控制/通信、参数搜索/编译摊销等；
- v：每shot读出/解码/证书的成本预算；若用平均成本，需包含所有成功/失败路径；
- F：失败条件下经典回退的期望成本；
- T：相同输出要求、有竞争力的经典对照耗时。

由于全体失败概率为`(1-s)^S`，期望总时间为

`E[T_hybrid] = A+S(t+v)+(1-s)^S F`。

这是固定整批执行策略，未采用提前停止来免费减少shot成本。
令`B=A+S(t+v)`。若`B≥T`，即使每批都成功也不能严格加速。
若`B+F<T`，所有s都在模型内满足条件。其他情况下，F>0且

`s > 1 - ((T-B)/F)^(1/S)`。

F=T时简化成`B < [1-(1-s)^S] T`。
若每shot事件不iid，使用整批成功概率q即可：`B+(1-q)F<T`。
还可反求量子单shot时间上界`t < (T-A-(1-q)F)/S-v`，或证书成本上界
`v < (T-A-(1-q)F)/S-t`。负的上界表示该组参数不可能获益。
这些等式给出模型内必要且充分的严格期望时间条件；真实应用还需资源和证书前提成立。
输出精确性由可靠证书与精确回退保证，s不足只影响运行时间；未将概率输出许可偷偷引入合同。

## 四、输入证据与可替代方案

1. 逻辑门数/调度：构造推导；小规模核验，无需真实量子机。
2. 逻辑到物理资源与时间：QDK纠错/蒸馏模型；直接估计大规模电路，无需大状态模拟。
3. s或q：可采用适用算法的理论下界、可精确计算的特殊结构、经验证且明示外推范围的模型；
   本轮一般MaxCut未取得此依据，因此反求门槛，保留参数。
4. 大规模经典T、证书v、回退F：优先实测；无法实测时采用有出处的算法成本模型或条件坐标。
   本轮没有把旧3秒超时替换成完成时间，也没有把小图MILP拟合外推到100节点。

小规模理想态中“全局最小mask及其补集”概率为r；仅在证书对这个目标完备且可靠、
物理估计e能控制输出事件概率偏差时，才有`s≥max(0,r-e)`。若证书只覆盖目标子集，
需进一步计入覆盖损失。QDK给出错误模型参数不等于自动证明所有这些前提。

本轮报告的是**明确假设下的潜在优势条件**，不是已有机器的实测收益；它可以在没有
100qubit可用设备的情况下完成，并指导需要验证的成功率/成本指标。
