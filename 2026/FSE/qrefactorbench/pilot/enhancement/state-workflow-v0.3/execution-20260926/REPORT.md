## 实验实际做了什么

使用原lit-009 C输入，5份初稿各派生4份独立修订：D初稿，S自检，A词法依赖分析，
V开发语义反馈，AV两者。四份修订共享同一初稿，不看彼此响应，各只修订一次。
每组轮换分支顺序，单轮600秒超时，所有25个预定位置都保留。

开发检查为3请求/13个pivot状态；保留检查为12请求/44个pivot状态，均来自同一个
程序母案例。保留输入没有作为修订反馈提供；它们不是独立母案例保留集。
初稿先审核再产生反馈；全部模型调用结束后，冻结20份修订的原文绑定才执行保留检查。
协调者以 `AI_REVIEW_PENDING` 转录，不是独立人类审核或自动自然语言裁判。

启动时日常CLI已自动更新到0.157.0，运行器拒绝该版本。本轮使用本机保留且哈希
匹配批准协议的0.156.1；没有安装、改系统配置或修改冻结协议。调用条件和离线预检
详见[原实现说明](../README.md)及[授权](../campaign/authorization.json)。

## 唯一明确错误初稿的配对

第2组初稿要求候选幅值“≥所有候选，且>所有更早候选”。原程序的有限输入可经消元
产生NaN。例如开发状态只剩一个NaN值时，该谓词不标记任何索引，而原Python `max`
保留这个索引。该反馈只反驳局部谓词；初稿另外声明的经典验证与回退没有因此被判错。

| 第2组版本 | 保留检查 | 原文中的变化 |
|---|---|---|
| D | 8/44状态存在反例 | 明确的≥所有、>更早谓词 |
| S | 两种解释均被反驳，分别8/44和3/44 | 改为“not less”措辞，未解决NaN比较语义 |
| A | 8/44状态存在反例 | 增加依赖讨论，保留原比较谓词 |
| V | 44/44有限通过 | 明确首元素初始化、按序遍历、仅在严格>时更新 |
| AV | 44/44有限通过 | 同样给出按序严格>更新，并保留动态状态说明 |

V与AV给出的局部规则可以直接转录为：

```python
best = indices[0]
for candidate in indices[1:]:
    if values[candidate] > values[best]:
        best = candidate
```

这里 `values` 是当前pivot幅值；严格比较自然保留原操作对NaN的顺序行为。
这是对**选择关系**的有限验证。它仍可能需要线性扫描，模型也承认可逆实现、数据访问、
经典验证成本未解决；没有生成或执行量子实现。两份成功修订来自同一份错误初稿，
不能当作两次独立修复机会。V和AV在这个机会上的结果相同，无法证明分析的额外贡献。

## 其它观察及解释边界

- 第1组初稿缺少具体比较规则。S后来提出的“没有更大值、没有更早相等值”谓词有3个
  失败状态；AV给出有限值条件下的明确规则。A改善了“顺序max而非数学最大值”的说明，
  但仍把实际oracle构造留空；不会替它补写算法再给通过分。
- 第3组初稿没有候选；S逐字重复初稿，A保持无计划，V和AV新增了pivot计划但仍未给出
  可唯一转录的完整规则。V/AV收到的“证据不足”反馈本身含pivot范围提示，候选变化
  可能受该提示影响，不能归因于反例验证或普遍WHERE能力改善。
- 第4组初稿提名整个函数，从函数定义行开始，词法工具返回不支持；A/AV仅把边界改到
  第一条可执行语句，仍无映射。V新提的具体谓词有3个失败状态。未知→新增错误主张
  与原先正确→退化不是同一种事件，分别保留。
- 第5组选择QUBO。缺少具体编码/系数或超出当前解释器范围的部分保持未知，不把允许的
  替代家族直接判错。额外Grover主张的歧义/有限条件如上表所述。

分析工具实际提供了3份词法清单、1份空清单、1份不支持结果。它是基于模型提名的
语句级清单，不是自动候选发现、可靠程序切片或数值可达性分析。
五份初稿中只有1份提供了明确可反驳的具体谓词；其余4份不是“正确初稿”。
修订中V的计划数量为5/5，AV为4/5，D/S/A各3/5；计划数量不是语义正确率。
25份回答均建议保留经典，实际适用性和benchmark支持均填false；这些常量也不区分质量。

## 可支持的结论与下一步

本轮支持：**具体反例反馈在一次配对中促使同一模型把错误的数学最大值谓词改为
与程序一致的有序选择规则，并通过有限保留检查；仅列依赖关系在这次机会中没有同样效果。**
本轮也显示未绑定主张、替代公式、粗候选范围和提示因素会限制评测覆盖。

不能据此声称普遍增强、统计显著、完整合同保持、量子优势或组合方法优于单独验证。
程序与失败类型是基于历史已知问题选择的；只有一个母案例、一个明确错误初稿机会，
协调者知道开发背景，原文转录仍待独立复核。本轮25次授权已耗尽，不补测或挑选重跑。

下一步可先离线整理三项改进设计：未绑定主张如何请求必要形式信息；分析如何接住
空候选/函数级候选；如何增加“仅pivot提示、无验证证据”的控制以隔离提示效应。
这些尚未实现或运行；新实验须先形成具体配置并取得新授权，不在本轮临时改条件。
