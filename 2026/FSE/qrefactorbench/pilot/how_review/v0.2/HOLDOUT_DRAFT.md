  A/B虽未运行，仍与C同母，不能重新当独立保留集。未观察的A/B可用于配对诊断。

## 建设和冻结流程提案

1. 先由研究者/评审者审核十例合同义务，尤其 tie 与未定控制的判断边界。
2. 记录候选新来源及排除理由，核对许可/改编差异；暂不采集新题或发布。
3. 为拟纳入案例建立原经典核、必要周边行为检查和可接受方案范围；AI提案仍待审。
4. 冻结审核协议、数据谱系、输入allowlist、样本/运行数、失败处理和报告方式。
5. 再单独授权模型或 Agent 执行；保留首次输出、版本、工具、预算和失败。

## 运行与分析提案

- GPT/Codex 和 DeepSeek/API 分别记录脚手架、effort、token上限、超时、工具与费用。
  相同 effort 名称或 token 数不代表等计算量；必要时报告各配置预算曲线。
- 预先决定每模型每母案例重复次数；不只重试失败模型/失败题后替换首次成绩。
- 语义记录与交付失败分开；不删除失败题改变分母。有限样本先报告逐母案例配对差异。
- 若计算区间/检验，统计单位是独立母问题/谱系组，重复样本和合同变体是组内观察。
  没有根据当前便利样本伪造 power 或保证某个题数足够。
- Agent 可见的调试测试与最终隐藏检查分开；经典全量回退的计算成本计入记录。
  不允许把最终隐藏反馈反复喂回同一轮系统后仍称一次保留集评测。
