## lit-002：覆盖与 tuple tie

原核按基数枚举，再按 `itertools.combinations(range(n),r)` 顺序返回第一个覆盖。
因此固定基数下，应选择索引元组字典序最小的解。

Sol 的次级项 `sum 2^(n-1-i)*(1-x_i)`：两个同基数集合第一个不同的位置 i，
选择 i 的集合有更小的元组，也有更小的次级项，因为该位权重大于所有后续权重之和。
取 `A=2^n`，整个次级项范围至多 `2^n-1`；取 `P=A*n+2^n` 大于无惩罚项上界。
这支持其核心 QUBO 的可行性、基数和 tuple 次序；不支持硬件精度或量子求解保证。

Astra 的 `sum x+(n+1)*uncovered`：不合法解至少 n+1，全选可行且成本 n。
可行解仅按基数排序。因此恰好保留所有最小覆盖，**没有编码 tie**；回答明确承认这一点。

Flash 分支取 n=2、边(0,1)，w=(2,1)，基数系数3、未覆盖惩罚10。
这些数由审核者实例化，满足主次目标支配；最小能量选(1)，原合同选(0)。
Pro 分支取 n=4、边(0,1),(0,2),(1,3),(2,3)，A=1、P=10、C=1/32，满足 C<A/2^n。
最小能量选 numeric mask 6，即(1,2)；原合同选(0,3)，mask 9。
两个 witness 均经过原 `prepare_request` 和 `min_vertex_cover_bruteforce` 核验。
Flash 的另一两阶段提案及两模型所述经典回退不被这两个反例一并否定。

实际枚举 n=0..5 的全部 **1,100** 个简单无向图，Sol 比较唯一 tuple 最优，
Astra 比较全部最小基数解集合。执行前检查受信源码与公开 C 包的编号源码一致。

## lit-003：替代家族与有序解

one-hot `x[v,s]`、每顶点一 slot 与相邻顶点不同 slot，对应源码 `available/place`。
非相邻顶点可共用 slot；没有额外容量约束。Search/QUBO 均可作为条件路线。

Flash 对合法赋值采用基数 B>=k 的位置数，Pro 用基数 k+1 的位置权重。
第一不同数字的增量大于后续数字可抵消的最大量，因而顺序与赋值向量字典序一致。
实际检查 n,k=0..4 的 **499** 个赋值向量，取 Flash 允许的 B=k。
仅证明/核对合法 one-hot 态的排序；没有检验所有非法 bitstring 的惩罚支配。
Pro 明确未解决 lambda/mu 界，Flash 未给出此界，Sol 的位置权重/前缀步骤尚待具体化。

Astra 的逐前缀方案：每次选择仍存在合法后缀的最小 slot，归纳得到字典序最小解。
这依赖精确存在性判定。Grover 未找到解不能作为精确否定；回答保留认证义务。
没有运行量子存在性算法、没有证明复杂度收益或全部 Python 异常行为。

边界：完整函数为 agenda.py:28–57，Flash 到56。保留57行 return 可能成立，需交代
替换片段给 assigned 的结果；不是仅凭少一行就判行为错误。

## lit-004：最大团与 numeric-mask tie

原程序按 mask 递增枚举，只在基数严格增大时替换，因此同大小取最小 mask。
Astra：B=2^n，A=nB+1；不可行能量 >=A-nB>0，空解为0。可行域中 B 支配 mask 范围。
Flash：M=2^n，P=nM+2^n，是其 P>nM+sum(2^i) 的合法实例；同理成立。

Pro：若选择集合有冲突，删去某冲突顶点能量变化为 `A-P*d-epsilon*2^i<0`
（d>=1、P>A、epsilon>0）。因此最小态可行。再取
`0<epsilon<A/(2^n-1)`（n>0），cardinality 支配 mask 范围；本次取 A=1、P=2、
epsilon=1/(2*2^n)。这是对回答条件的审查者实例化，不冒充回答给出的数值。
n=0 直接返回空集。实际枚举 **1,100** 个图、各三种能量的全部极小态，与核心合同核对。

Sol 的两阶段构造合理，但没有本次可核对的具体单阶段系数，不能给同样的编码证据。
25–29 保留解码、24–30 包含模式判断和解码，均有可辩护边界；没有验证生成补丁。

## lit-006：背包逐实例充分界

原输入允许正整数 weight、非负整数 value/capacity；DP 在最大 value 下选最小 mask。
Astra 给 B=2^n，A>B*sum(v)，能量 `-B*V+mask+A*(W+s-C)^2`。
任一非零整数残差有惩罚至少 A，负目标最低 -B*sum(v)，故能量>0；空解 s=C 能量0。
非负 slack 排除超重解的零残差；可行 mask 都有 s=C-W，B 又支配整个 mask 范围。
所以精确整数能量的最小决策位符合原核 value/mask 合同。

取标准非负二进制 slack，可表示0..C并可能包含更大的数；检查包括所有 slack bitstring，
没有只检查可行 slack 来绕过惩罚验证。取 A=B*sum(v)+1。
实际 n=0..3、weight=1..3、value=0..2、capacity=0..4，**4,100** 个实例，
与不变的原 `choose` 核和独立子集枚举核对。回答未提交 slack 电路或可执行迁移。
Sol/Flash 明确留白；Pro 缺统一数值上限的理由不能阻止逐实例求界，但仍仅编码为
未解决，不把一个尚未具体化的公式自动当反例。

## lit-009：子区域而非整个算法名称

对有限浮点列定义 `better(i,p) := abs(a[i])>abs(a[p]) or (equal and i<p)`。
它只依赖候选和 incumbent，无需预知全局最大值。每次改进使有序键严格改善，
若能精确判断没有更优项，则得到 Python max 的首个最大绝对值索引。
在 {-2,-1,0,1,2} 上长度1..5共 **3,905** 列，从每个起始 incumbent 做经典检查通过。
这支持条件谓词思路，并反驳 Pro 排除该思路时使用的必要性理由；不把整题参考改为 YES。

这不是量子搜索运行；不包含 NaN/Inf，不证明这些状态从完整程序是否可达。
Astra 明确给非有限状态原实现回退，Sol 仍留下全面 binary64 比较义务。
数据装载、比较器、负结果认证及收益全部未解决。Flash 没有最终答案，不审核 reasoning。
