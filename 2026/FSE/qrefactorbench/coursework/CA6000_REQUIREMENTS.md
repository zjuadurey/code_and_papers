# CA6000 作业要求与交付边界

来源：用户提供的课程作业说明。截止日期：2026-09-20。

课程要求提交 **report + code**。用户另要求 5–10 页 PPT；因此 PPT 不能替代
包含数据来源、清洗、统计、训练和评估的书面报告。

| 评分内容 | 必须保留的证据 |
|---|---|
| 获取数据集 | 来源、导入代码、原始数据与版本/哈希 |
| 数据检查 | 缺失、重复、类型/范围、异常值检查的实际输出 |
| 数据清洗 | 修复步骤；如人为注入错误，明确区分原始与污染副本 |
| 基础分析 | 均值、中位数、方差、类别/目标分布和可视化 |
| 训练神经网络 | 模型定义、真实训练过程、固定随机种子和数据划分 |
| 评估预测 | 未参与训练/调参的测试数据、准确率及适合任务的补充指标 |
| AI 使用说明 | 哪些代码/调试/文档由 AI 辅助，哪些检查实际运行 |
| 交付 | 可重现代码、报告、5–10 页 PPT、实际产物 |

老师主要评价方法和开发步骤，而不仅是最终分数。没有必须实时调用 LLM 或
必须有 GUI 的要求。不能把使用 AI coding assistant 冒充训练了神经网络。

此前的 QRefactor 可视化演示（`app.py`、`index.html`）及尚未完成的幻灯片
生成草稿（`build_slides.py`）展示了程序分析回放和量子模拟，**单独不足以
满足课程要求**：它们没有数据集上的神经网络训练与预测评估。
保留这些文件作为独立研究 demo，不将其标为已完成的 CA6000 作业。

课程实验必须与 QRefactorBench 的 DRAFT 标签、冻结输入、模型实验与评估器隔离。
不得为了神经网络训练制造或升级 benchmark 科学标签。

## 已确认的课程方向

用户明确选择：**基于 QRefactorBench 搜索案例的布尔约束可满足性预测**。
从经典程序派生不同输入实例，用穷举得到 SAT/UNSAT 标签，训练 MLP。
这不是“量子化适用性”分类；也不是扩大科学 benchmark 的案例数。
用户随后要求 **PPT 使用英语**；英文报告、PPT、图表和运行界面统一放在
`sat_case_study/`，此前公开医疗数据方案保留为未采用备选。
