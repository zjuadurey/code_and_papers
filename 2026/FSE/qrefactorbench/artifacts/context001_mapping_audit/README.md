## 2. 逐边恒等式与 QUBO

| x_i | x_j | 是否同组 | 1−x_i−x_j+2x_ix_j |
|---:|---:|---|---:|
| 0 | 0 | 是 | 1 |
| 0 | 1 | 否 | 0 |
| 1 | 0 | 否 | 0 |
| 1 | 1 | 是 | 1 |

令 W=Σ_(i<j) w_ij，则

```text
C(x) = Σ_(i<j) w_ij (1 − x_i − x_j + 2 x_i x_j)
     = W + Σ_i a_i x_i + Σ_(i<j) b_ij x_i x_j
a_i  = −Σ_(j≠i) w_ij
b_ij = 2 w_ij
原函数的跨组得分 = W − C(x)
```

因此原函数最大化跨组得分与最小化 C 完全等价；所有全局最优分组的集合一致。
这来自二元逐边恒等式及求和，对声明域内任意设备数/整数权重都成立，
不是从 98 个样本归纳出的普遍结论。有限运行检查的是公式转录、索引、源码对应和接口。

审计使用上三角多项式约定，每个二次项只出现一次。若使用对称矩阵 `xᵀQx`，
对角为 a_i、对称非对角为 w_ij；不能把 2w_ij 填入两侧而将交互重复加倍。
常数 W 对 argmin 没影响，但要恢复准确冲突分数；不能省略后仍声称能量就是冲突分数。

## 3. Ising / 条件量子表达的边界

代入 `z_i=1−2x_i`，得到

```text
C(z) = W/2 + Σ_(i<j) (w_ij/2) z_i z_j
H    = (W/2) I + Σ_(i<j) (w_ij/2) Z_i Z_j
```

在对应的计算基态上，H 的本征值等于该分组的冲突权重。这给出一个具体对角成本
Hamiltonian；`n` 个逻辑变量的直接基态编码可以表达分组，**不是整个实现的实际物理
量子位数、线路深度或可部署性估计**。n=0 是直接返回空报告的经典边界。

标准 MaxCut → Ising 的一般方法可对照
[Qiskit Optimization 0.7.0 官方教程](https://qiskit-community.github.io/qiskit-optimization/tutorials/06_examples_max_cut_and_tsp.html#Weighted-Max-Cut)。
该教程也讨论 QAOA 的启发式求解；本例采用的常数/符号由上面的同组冲突目标独立推导，
不直接复制教程的最大化目标符号。本次未运行教程或安装量子优化库。

条件 HOW 可以沿“构造成本表达 → 合适的量子优化尝试 → 按设备索引解码 → 原函数
复算/生成报告”讨论。**我们只核查了成本表达与经典解码衔接**，未指定唯一算法、参数、
成功概率或 shots。QAOA-style 求解、有限精度、实际量子测量寄存器位序尚未实现/验证。
程序中的位数组按设备位置排列；未来不能把量子 API 打印的 bitstring 顺序直接照搬。

## 4. 用三设备例子审查

设备顺序是 pump、fan、chiller，权重分别为 w_01=4、w_12=3、w_02=1。

```text
C(x) = 8 − 5x_0 − 7x_1 − 4x_2
         + 8x_0x_1 + 2x_0x_2 + 6x_1x_2
H    = 4I + 2Z_0Z_1 + (1/2)Z_0Z_2 + (3/2)Z_1Z_2
```

| mask（Σ 2^i x_i） | x 按设备顺序排列 | 冲突权重 |
|---:|---|---:|
| 0 | (0,0,0) | 8 |
| 1 | (1,0,0) | 3 |
| 2 | (0,1,0) | 1 |
| 3 | (1,1,0) | 4 |
| 4 | (0,0,1) | 4 |
| 5 | (1,0,1) | 1 |
| 6 | (0,1,1) | 3 |
| 7 | (1,1,1) | 8 |

最优 mask 是 2 和 5。源码选择 2：window 0 为 fan，window 1 为 pump/chiller。
测到 mask 5 虽然能量也正确，但会交换时段，进而改变移动清单，不能直接当作完整合同通过。
两时段互换的互补对称性不保证是所有并列解的全部来源；此处没有制定通用并列修复算法。
